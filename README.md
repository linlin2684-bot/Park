# 🎡 兩人遊樂園

只屬於我們兩個的遊樂園：獎勵卡票夾、刮刮卡、扭蛋、轉盤、集點章、旅行基金、足跡地圖、年度清單、時光膠囊……

## 檔案
| 檔案 | 用途 |
|---|---|
| index.html | 網頁入口 |
| app.js | 主程式 |
| data.js | 卡片、題目、任務等內容（想改內容改這裡） |
| store.js | 資料存取（Firebase / 試玩模式） |
| config.js | **貼上你的 Firebase 設定** |
| style.css | 樣式 |
| firestore.rules | 貼到 Firebase 的安全規則（不用上傳也可以） |

`config.js` 還沒填的時候，app 會進入「試玩模式」，資料只存在這支手機。
